# Passage 0.1.2 — 2026-10-04

A bug-fix release. Upgrading is recommended if you read diagrams.

- Diagram fullscreen now uses the whole dialog: tall sequence diagrams and small flowcharts are fitted to the available space (up to 4×) without scrolling, and the diagram re-fits when you resize the window.
- Closing fullscreen returns the diagram to its inline size and restores your reading position and focus.

How to update: pull the latest `main` (or download the 0.1.2 ZIP) and restart the reader. Your settings are untouched.

Trusted-local use only, as before; see the [security policy](../SECURITY.md).
