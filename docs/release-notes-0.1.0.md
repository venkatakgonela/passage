# Passage 0.1.0 — prepared 2026-10-03

First source release, pending maintainer publication.

- Read technical Markdown locally without editing source documents or creating an account.
- Navigate folders with title filtering, content search, Quick open, reference Peek and a return Trail.
- Read sanitized math, isolated flowchart/sequence/ER diagrams, tables and bounded local PNG/JPEG images.
- Compare matching sections, keep separate reading lists and passage notes, and export notes or inert HTML.
- Choose Light/Dark/Auto, Fill or a line limit, and Focus mode; keyboard controls and narrow drawers are included.
- Follow the ten-minute tutorial and captioned synthetic tour; run locally with Python, without a runtime install/build step.

Trusted-local only, one server process, no hostile-filesystem sandbox or security certification. Windows/Firefox/Safari are untested. Remote live images can make network requests; offline export omits them. See [reference](reference.md), [security policy](../SECURITY.md) and [known rendering limits](known-rendering-issues.md).
